# Contributing

Code is written by agents. Humans review, file bugs, and run the kernel. Read [AGENTS.md](AGENTS.md) and [README.md](README.md) first.

PR checklist: the [standing gates](docs/ROADMAP.md#how-to-read-this), the [rules from the kernel review](AGENTS.md#rules-from-the-kernel-review), and the [Do not](AGENTS.md#do-not) list in AGENTS.md: nothing copied or translated from GPL or LGPL sources, a note for every new dependency, and no test disabled, skipped, retried, or given a longer timeout to make CI green.
